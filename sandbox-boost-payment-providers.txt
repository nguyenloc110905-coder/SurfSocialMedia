Surf Market Boost - Sandbox payment providers

Gateway sandbox đang hỗ trợ qua sandbox chính chủ:
- ZaloPay Sandbox
  - Server gọi API create order ZaloPay sandbox và mở orderurl do ZaloPay trả về.
  - Cần cấu hình ZALOPAY_APP_ID, ZALOPAY_KEY1, ZALOPAY_KEY2.

- VNPAY Sandbox
  - Server tạo URL https://sandbox.vnpayment.vn/paymentv2/vpcpay.html với vnp_SecureHash.
  - Cần cấu hình VNPAY_TMN_CODE, VNPAY_HASH_SECRET.

- MoMo Sandbox
  - Server gọi API https://test-payment.momo.vn/v2/gateway/api/create và mở payUrl do MoMo trả về.
  - Cần cấu hình MOMO_PARTNER_CODE, MOMO_ACCESS_KEY, MOMO_SECRET_KEY.

Không có UI thanh toán tự dựng trong Surf. Surf Market chỉ chọn cổng, mở tab sandbox chính chủ, rồi chờ API server báo paid.

Cách test trên web:
1. Vào Surf Market.
2. Bật quảng bá khi tạo sản phẩm hoặc bấm Quảng bá bài niêm yết ở listing đã đăng.
3. Chọn ngân sách.
4. Bấm Đăng/Quảng bá để mở modal thanh toán.
5. Chọn ZaloPay Sandbox, VNPAY Sandbox hoặc MoMo Sandbox.
6. Tab mới mở cổng sandbox chính chủ của provider.
7. Hoàn tất thanh toán trên cổng đó.
8. Gateway redirect/callback về server, server cập nhật payment session thành paid.
9. Market nhận status paid từ API rồi mới tạo/bật quảng bá.
