FASTIFY MESSAGE SKELETON (CODE TAY) - SURF
==========================================

Muc tieu
--------
- Lam module nhan tin giong LinkedIn/FB.
- Giam API request/s bang Socket.IO + Redis.
- Ban code tay theo tung file, tung buoc.

Kien truc toi thieu
-------------------
1) REST chi de load du lieu ban dau (inbox, history).
2) Socket de gui/nhan tin nhan realtime.
3) Redis de scale + presence + unread cache.
4) Firestore de luu message ben vung.

----------------------------
1) env.ts -> doc bien moi truong.

3) auth.ts -> middleware REST.

6) messages.ts -> REST inbox/history.

[src/app.ts]
------------
import Fastify from 'fastify';
import cors from '@fastify/cors';
import { env } from './config/env.js';
import { registerMessageRoutes } from './routes/messages.js';
export const buildApp = async () => {
  const app = Fastify({ logger: true });
  await app.register(cors, { origin: env.frontendOrigins.length ? env.frontendOrigins : true, credentials: true });
  app.get('/api/health', async () => ({ status: 'ok' }));
  await registerMessageRoutes(app);
  return app;
};

[src/index.ts]
--------------
import { buildApp } from './app.js';
import { createSocketServer } from './realtime/socket.js';
import { env } from './config/env.js';
const app = await buildApp();
await createSocketServer(app);
await app.listen({ port: env.port, host: '0.0.0.0' });

Event contract (de frontend lam theo)
-------------------------------------
Client -> Server:
1) conversation:join(conversationId)
2) message:send({ conversationId, text, clientMessageId? }, ack)
3) message:read({ conversationId, messageId })
4) typing({ conversationId, isTyping })

Server -> Client:
1) message:new({ conversationId, message })
2) conversation:updated({ conversationId, lastMessageText, lastMessageAt })
3) message:read({ conversationId, messageId, readerId, readAt })
4) typing({ conversationId, userId, isTyping })

Checklist dung de tranh loi
---------------------------
1) Validate user la member cua conversation truoc moi action.
2) Message text trim + gioi han do dai.
3) Dung cursor pagination, khong load full history.
4) Typing debounce 300-500ms.
5) Read receipt batch, khong spam event.
6) Redis chi la cache/realtime; Firestore moi la source of truth.
