If Firestore returns FAILED_PRECONDITION:

5. MSG-3 Send message
POST http://localhost:4000/api/conversations/<CONVERSATION_ID>/messages
Authorization: Bearer TOKEN_A
Header: Content-Type: application/json
Body:
{
  "text": "hello from A"
}

Expected:
- 201 OK
- response has:
  - item.id
  - item.conversationId
  - item.senderId
  - item.text
  - item.createdAt
  - conversation.id
  - conversation.lastMessagePreview
  - conversation.lastMessageAt

6. Firestore check after send message
Check:
- conversations/<CONVERSATION_ID>
- conversations/<CONVERSATION_ID>/messages/<MESSAGE_ID>

Expected:
- parent conversation updated:
  - lastMessagePreview
  - lastMessageAt
  - unreadCountByUser
- messages subcollection has new message doc

7. MSG-4 Realtime message delivery
Open surf-client in browser for user B and login.
In browser console:
const { getSocket } = await import('/src/lib/socket.ts');
const socket = getSocket();
socket.off('message:new');
socket.on('message:new', (payload) => console.log('message:new', payload));

Then send another message from A using Postman.

Expected:
